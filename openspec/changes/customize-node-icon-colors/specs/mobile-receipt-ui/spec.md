## ADDED Requirements

### Requirement: 節點圖示自訂色彩與預設調色盤
系統 SHALL 支援為記帳節點指定代表色彩，並在圖示挑選器抽屜（IconPickerSheet）提供一組固定的精選預設色圈（Swatches）供點選，並以純向量圖示線條顏色呈現。

#### Scenario: 在圖示抽屜中選取顏色與圖示
- **GIVEN** 使用者在新增或編輯節點時開啟圖示挑選抽屜
- **WHEN** 點選色圈清單中的指定顏色（如常青森綠），並點選任一向量圖示
- **THEN** 系統將該圖示與代表色一併帶入節點表單，並自動關閉抽屜

#### Scenario: 節點於全站呈現對應圖示線條色彩
- **GIVEN** 節點已設定特定代表色彩（如 `#2D6A4F`）
- **WHEN** 節點圖示呈現在收據卡片、橫向帳戶列或圖論結餘清單中
- **THEN** 向量圖示以該指定色彩之線條渲染；未設定色彩者則維持預設墨黑色
