# Delta Spec: Mobile Receipt UI (手機收據記帳介面)

## MODIFIED Requirements

### Requirement: 數位收據風格卡片流展示
系統 SHALL 將每筆款項流向（Edge）以具有實體票據感的「數位收據卡片」呈現，並依據來源節點與目標節點的 `owner` 屬性自動標記交易性質（收入、支出或內部轉帳）。

#### Scenario: 檢視數位收據清單
- **GIVEN** 本地存在多筆交易紀錄
- **WHEN** 使用者進入首頁
- **THEN** 介面以垂直收據卡片流展示每筆收據，卡片具有虛線撕紙質感、清楚標示「來源帳戶 ➔ 目標帳戶」與格式化等寬金額

#### Scenario: 依據邊界自動呈現收支或轉帳識別標記
- **GIVEN** 存在不同擁有者流向的交易收據
- **WHEN** 在首頁收據清單中檢視
- **THEN** 系統對跨越邊界流入的收據標示「收入」、流出的標示「支出」、內部調度的標示「轉帳」
