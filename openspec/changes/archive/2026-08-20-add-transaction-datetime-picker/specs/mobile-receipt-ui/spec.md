## MODIFIED Requirements

### Requirement: 單手操作快捷連線記帳底部抽屜 (Bottom Sheet)
系統 SHALL 提供專為手機單手操作設計的記帳抽屜，支援快速點選「資金來源」、「資金目標」、輸入金額、自訂交易日期時間（含時與分）或使用預設快捷按鍵（如現在、昨天、前天），以及選填備註。

#### Scenario: 透過手機底部抽屜完成連線記帳（預設當前時間）
- **GIVEN** 使用者在手機首頁點擊底部「＋ 記一筆收據」按鈕
- **WHEN** 底部彈出抽屜選單，時間預設為當前最新本地時刻且高亮「⚡ 現在」，使用者未調整時間，點選來源節點 `現金皮夾`、目標節點 `餐飲飲食`，輸入金額 `150` 並點擊完成
- **THEN** 系統建立一筆新的圖論邊，其時間戳記為當前時間，抽屜關閉，首頁收據清單與頂部餘額看板立即即時更新

#### Scenario: 透過快捷按鍵補記昨日帳目並保留時分
- **GIVEN** 使用者開啟記帳抽屜
- **WHEN** 點擊「昨天」快捷標籤，系統將日期自動位移至昨日並保留目前設定之時分，同時高亮「昨天」標籤
- **AND** 選擇資金來源與終點並輸入金額送出
- **THEN** 系統建立一筆帶有昨日對應時間戳記的收據，並在收據清單中依時間排序至昨日位置

#### Scenario: 自訂精確日期與時分（包含未來時間）與雙向標籤連動
- **GIVEN** 使用者開啟記帳抽屜
- **WHEN** 透過日期時間選擇器選取指定之年月日與時分（例如未來的 `2026-08-25 10:00`，或過去的特定日期）
- **THEN** 快捷標籤若非今天/昨天/前天則自動取消高亮狀態；若選中昨天則自動高亮「昨天」
- **WHEN** 填寫金額並送出
- **THEN** 系統以該選定時間之毫秒時間戳記建立收據紀錄

#### Scenario: 重新開啟抽屜時狀態重設
- **GIVEN** 使用者剛補記了一筆昨日帳目或關閉了抽屜
- **WHEN** 再次點擊「＋ 記一筆收據」開啟抽屜
- **THEN** 時間輸入框與快捷標籤自動重設為「當下最新本地時刻」與「⚡ 現在」，不殘留上次的自訂日期
