## ADDED Requirements

### Requirement: 統一節點表單底部抽屜 (NodeFormSheet)
系統 SHALL 在新增節點與編輯既有節點時，統一採用相同的底部抽屜（Bottom Sheet）介面與欄位排版進行資料輸入與維護。

#### Scenario: 透過抽屜新增節點
- **GIVEN** 使用者位於帳戶與對象管理頁面
- **WHEN** 點擊頂部「＋ 新增」按鈕
- **THEN** 系統由底部滑出標題為「新增節點」的抽屜，提供圖示與名稱並排輸入，點擊「建立節點」完成新增並關閉抽屜

#### Scenario: 透過抽屜編輯與封存節點
- **GIVEN** 使用者位於帳戶與對象管理頁面
- **WHEN** 點擊清單中的任一節點卡片
- **THEN** 系統由底部滑出標題為「編輯節點」的抽屜，帶入該節點目前之資料，提供「儲存修改」與「封存節點」按鈕
